# Workout Tracker App

This is a single-page application (SPA) built with Vite, React, and TypeScript for tracking your workouts. You can:
- Add workouts with date and notes
- Select muscle groups for each workout
- Add exercises and, for each exercise, add sets with reps and weight
- All data is stored locally in your browser (localStorage)

## Getting Started

### Development
- Run `npm run dev` to start the development server
- Open [http://localhost:5173](http://localhost:5173) in your browser

### Build
- Run `npm run build` to create a production build

### Preview
- Run `npm run preview` to preview the production build

## Project Structure
- `src/` — main source code
- `src/App.tsx` — main app component
